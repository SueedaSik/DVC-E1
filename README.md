### 3. Git Befehle angewendet
Ich habe folgende Befehle verwendet:
- `git status` – zeigt den aktuellen Stand
- `git add` – Dateien zum Commit vormerken
- `git commit` – Änderungen speichern
- `git push` – auf GitHub hochladen
- `git pull` – von GitHub herunterladen
- `git diff` – Unterschiede anzeigen
- `git rm` – Datei löschen
- `git mv` – Datei umbenennen
